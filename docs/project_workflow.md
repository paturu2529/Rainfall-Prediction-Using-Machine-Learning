# Project Workflow

## Rainfall Prediction Using Machine Learning with Python

### 1. Dataset Collection
The project uses the Rain in Australia dataset (`weatherAUS.csv`) obtained from Kaggle.

### 2. Data Preprocessing
The dataset is prepared by handling duplicate records, date values, invalid target values, and missing numerical values.

### 3. Exploratory Data Analysis
Exploratory analysis is performed to understand rainfall distribution, missing values, weather-feature distributions, and relationships between numerical variables.

### 4. Model Development
The project compares the following machine learning models:

- Dummy Classifier
- Logistic Regression
- Decision Tree
- Random Forest

### 5. Model Evaluation
The models are evaluated using classification metrics, including accuracy, precision, recall, F1-score, and ROC-AUC.

### 6. Rainfall Prediction
The Streamlit application provides an interface for entering weather measurements and obtaining a rainfall prediction using the trained Random Forest model.

### 7. Application Interface
The project provides data overview, exploratory analysis, model comparison, and rainfall prediction modules.
