# Dataset Description

## Rain in Australia Dataset

### 1. Dataset Overview
This project uses the Rain in Australia dataset, which contains historical Australian weather observations.

### 2. Dataset Source
The dataset is obtained from Kaggle.

Dataset Link: https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package

### 3. Target Variable
The target variable used for prediction is `RainTomorrow`.

- Yes – Rainfall is expected on the following day.
- No – Rainfall is not expected on the following day.

### 4. Selected Input Features

The project uses the following 14 numerical weather features:

1. MinTemp
2. MaxTemp
3. Rainfall
4. Evaporation
5. Sunshine
6. WindGustSpeed
7. Humidity9am
8. Humidity3pm
9. Pressure9am
10. Pressure3pm
11. Cloud9am
12. Cloud3pm
13. Temp9am
14. Temp3pm

### 5. Dataset Usage
The dataset is used for data preprocessing, exploratory data analysis, machine learning model training, model evaluation, and rainfall prediction.

### 6. Prediction Objective
The objective is to predict whether rainfall will occur tomorrow based on the selected weather measurements.
