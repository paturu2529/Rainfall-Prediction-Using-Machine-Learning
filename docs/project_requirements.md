# Project Requirements

## Functional Requirements

1. The application should load the Australian weather dataset.
2. It should clean and preprocess the dataset.
3. It should display exploratory data analysis visualizations.
4. It should train and compare multiple machine learning models.
5. It should predict whether rainfall is expected tomorrow.
6. It should display prediction results through a Streamlit interface.

## Software Requirements

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- SciPy
- Scikit-learn
- Joblib

## Hardware Requirements

- Computer or laptop
- Minimum 4 GB RAM recommended
- Internet connection for downloading dependencies and accessing the repository
