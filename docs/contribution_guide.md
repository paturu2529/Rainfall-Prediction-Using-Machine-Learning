# Contribution Guide

## 1. Introduction

This guide explains how contributors can work on the Rainfall Prediction Using Machine Learning project.

## 2. Project Requirements

- Python 3.8 or above
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- SciPy
- Joblib

## 3. Contribution Steps

1. Fork the project repository.
2. Clone the repository to your local system.
3. Create a new feature branch.
4. Make meaningful changes to the project.
5. Test the changes before submitting.
6. Commit and push your changes.
7. Create a Pull Request on GitHub.

## 4. Code Quality

- Write readable and properly formatted Python code.
- Use meaningful variable and function names.
- Add comments where necessary.
- Avoid committing API keys and sensitive information.

## 5. Pull Request Guidelines

- Provide a clear PR title.
- Explain the changes made.
- Mention the files modified.
- Ensure that the changes do not break existing functionality.

## 6. Conclusion

Contributions help improve the functionality, documentation, and usability of this project.
