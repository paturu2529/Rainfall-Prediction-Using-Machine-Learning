# Rainfall Prediction User Guide

## Introduction
This guide explains how to use the rainfall prediction feature in the Streamlit application.

## Steps to Use

1. Start the Streamlit application using `streamlit run app.py`.
2. Open the application in your web browser.
3. Navigate to the Predict Rainfall section.
4. Enter the required weather measurements.
5. Submit the input values.
6. View the predicted rainfall result.

## Prediction Model
The application uses a trained Random Forest pipeline to generate predictions.

## Important Note
The model is trained using Australian weather data. Its predictions should not be treated as official weather forecasts or assumed to be accurate for other geographical regions.
